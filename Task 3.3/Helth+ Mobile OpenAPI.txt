        - Payload: {

            "iat": "время выдачи",
            "exp": "время истечения (24 часа)",

        `Authorization: Bearer <token>`

      description: |
        Метаданные пагинации на основе offset.
        
        **Почему offset-based, а не cursor-based:**
        - Записи редко меняют порядок (дата приёма фиксирована)
        - Проще реализовать на стороне клиента (пациенты
          ожидают номера страниц, а не курсоры)
        - Не требуется поддержка real-time синхронизации
          для списка предстоящих записей
        
        **Расчёт страниц:**
        - Всего записей: total
        - Записей на странице: limit
        - Текущая страница: offset / limit + 1
        - Всего страниц: ceil(total / limit)

        - "offset"
